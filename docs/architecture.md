# Architecture

Nexus Assistant consists of:

## Telegram Layer

- Commands
- Keyboards
- Message Handlers

## Service Layer

- User Service
- Notes Service

## Repository Layer

- User Repository
- Notes Repository

## Database Layer

- SQLite Database

## Modules

- User Profiles
- Language Settings
- Notes Module

## Future Modules

- AI Assistant
- Automations
- Telegram Mini App
- Memory Search
- Voice Notes

## Long-Term Vision

Nexus Assistant evolves into Nexus Memory:

A digital memory platform that helps users
capture, organize, search and understand
their personal and business knowledge.
